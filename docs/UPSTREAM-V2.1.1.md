# daed v2.1.1 管理层适配记录

此分支以 daed 官方正式标签 `v2.1.1`（`b3043aa7ce07c774c65e546112aa2c7a1c12edb5`）为管理层来源。其 `dae-wing` 为 `dc503088945812c11235b35362d2bfa1a4c3bdf0`，官方发布包内嵌的 DAE 为 `85a1fc3c06e3765d143c868ba97ecd0be2aab4ea`。本项目继续固定 DAE v2.1.1 的 `dbae2e82d3ed5324e1648548720f8bbc8cde3882`，两者不可混称；`go.mod` 的 `replace => ./dae-core` 决定实际编译源码。

## 与此前 v1.27.0 集成版的差异

- Web：移植新版运行流量概览、节点延迟、分组订阅正则筛选、bootstrap resolver 输入及相关测试和界面修正；保留集成版已有的核心配置字段、节点延迟展示和旧设置兼容逻辑。
- 后端：移植官方 wing 的分组订阅绑定、运行概览和节点延迟 GraphQL；通过小型适配函数调用固定 DAE 核心当前的生命周期租约、异步健康观测和配置接口。
- 核心：不替换 DAE gitlink，不复制官方较早的内嵌核心。`ifindex-shutdown-join` 与 `sniffer-lifetime` 补丁仍可在当前固定核心上正向应用，反向校验不通过，因此仍保留；构建时继续校验补丁哈希。
- 构建：保留本项目既有依赖锁定和部署保护。上游 v1.27.0 至 v2.1.1 的 CI、发布流程、截图和大量依赖更新不直接搬入；`resizable` 仍使用当前锁定库的 API。没有把依赖更新视为功能适配完成。

## 验收边界

源码编译、Web 页面构建及自动测试只能证明候选工件可构建。管理页面、配置数据库、DNS、TCP/UDP、分流、服务重启和回滚需要对最终二进制单独验收。公开仓库的全新安装脚本不能用于覆盖现有 systemd 安装。未经运行验收，不应把本分支称为可上线版本。
