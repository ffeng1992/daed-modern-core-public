# Embedded backend

This directory contains the daed backend adapted by this project. It is built with the matching web interface and the pinned `dae-core` submodule from the repository root.

Use the root [deployment guide](../docs/DEPLOYMENT.md) for the supported fresh-install path and the root [compatibility manifest](../compatibility/versions.json) for pinned source revisions. Do not deploy this directory independently.

The backend and DAE core retain their upstream license and copyright notices in `LICENSE` and `dae-core/LICENSE`.
